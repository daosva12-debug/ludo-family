# Cómo jugar online

## Link fijo (recomendado)

Publicá la app una vez (Render/Railway) y usá siempre la misma URL.

Guía: **[LINK-FIJO.md](./LINK-FIJO.md)**

## Link temporal (solo pruebas)

```bash
npm run online
```

Copia el `https://….trycloudflare.com` que imprime.  
**Expira** cuando se apaga el proceso o la sesión.

## Cómo se juega (con cualquier link válido)

1. Todos abren la **misma** URL  
2. Uno: **Crear sala online** → nombre + color  
3. **Copiar invitación** / código  
4. Los demás: **Unirse**  
5. Anfitrión: **Iniciar partida**
